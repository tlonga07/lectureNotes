(Hint: first write out what pattern it produces.)

f(1) = 2, f(2) = 6, f(3) = 10, f(4) = 14

Base case: f(1) = 2
Recursive function: f(n) = f(n-1) + 4, n >= 2

S = {6, 21, 26}

Sum(n) is sum of all preceding int
Base case:
Sum(1) = 1

Recursive case:
Sum(n) = Sum(n-1) + n, n > 1

4) Give a recursive definition of the function Product(m, n), where Product(m, n) is the product of
the integer m and the nonnegative integer n:

Base case: 
Product(m, 0) = 0

Recursive Case: 
Product(m, n) = Product(m, n-1) + m, n > 0
