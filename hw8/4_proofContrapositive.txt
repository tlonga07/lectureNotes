Use the contrapositive to prove the following proposition:

If n is an integer and 3n + 2 is even, then n is even.

Contrapositive:
!Q = n is odd
!P = 3n + 2 is odd

Assume n is Odd
By odd definition n = 2k + 1 for some kk

n = 2k+ 1
3n = 3(2k + 1)

3n + 2 = 3(2k + 1) + 2
= 6k + 3 + 2
= 6k + 5
= 6k + 4 + 1
=2(3k+2) + 1 
3n + 2 is odd bc (k+2) is an int as k and 2 are both integers and 2(int) + 1 is def of odd num

When n is odd (not even), 3n + 2 is odd (not even), 3n + 2 being even implies n is even
